## 1.1.0 で変わったこと

- **依頼の聞き取りが固定時間に**: 「ヘイクロード」のあと、話し始めてから一定の時間(設定の「依頼を聞き取る時間」、15〜60 秒、既定 30 秒)の発話をまとめて 1 つの依頼にします。途中の間で切れません。「以上」と言えばすぐに送ります。画面下の帯に残り秒数が出ます。
- **テンプレートの共有ライブラリ**: 辞書の「テンプレート」タブの「…」に「共有ライブラリから取り込む…」、各テンプレートに「共有…」を足しました。ライブラリは GitHub の公開リポジトリ [openspeech-templates](https://github.com/Shintaro-Kano/openspeech-templates)(CC0 1.0)で、[一覧ページ](https://shintaro-kano.github.io/openspeech-templates/)からも CSV で取り込めます。取り込みは押したときだけ目録を取得し、共有はブラウザで GitHub の投稿フォームを開くだけです(アプリは何も送信しません)。
- **説明文を減らしました**: 単語登録の読み欄の下と、設定「音声コマンド」の先頭の説明、「登録しなくても働きます」の注意を外しました。
- **辞書の窓のテンプレート一覧が窓からはみ出さなくなりました**: 長いキーワードやモジュール名があると窓が主窓より広がり両側が切れていました。列の幅で「…」に切り、全文はマウスを乗せると出ます。共有ライブラリの一覧も同じ直しです。
- **「ヘイクロード」で文章の手直しも頼めます**: 文章を選んで(選ばなければ全文、3000 字まで)「文章を意味が一貫するように整えて、誤字や矛盾がないか確認して」のように頼むと、Claude が直した文で置き換えます(変更の数と、直せなかった矛盾の指摘を知らせます)。直後の Esc で戻せます。依頼に左右の語が無いのに左右が変わった答えや、長すぎる答えは使いません。選んだ範囲があるときだけ Claude の考える量を増やします。
- **依頼の指示も書き換えられます**: 設定「AI 訂正」の「依頼の指示を編集…」で `request.md` を開けます(訂正の指示は「訂正の指示を編集…」、`guidance.md`)。テンプレートの選び方・値の入れ方・手直しの規則がここにあり、空にすればアプリの既定に戻ります。`<!-- -->` で囲んだ部分は Claude に送られません。
- **訂正の指示(guidance.md)の既定を直しました**: 先頭の説明を送られない注釈にし(手元のファイルも次の起動で 1 回だけ直します。前の内容は `backup/` に残ります)、かなのまま残った医学用語を直す規則、数値と単位の書き分け、「かける → ×」「パーセント → %」を足しました。
