## 1.1.1 で変わったこと

- **「マイクを切る」で iPhone を放すようになりました**: iPhone をマイクにしているとき、「マイクを切る」を押しても iPhone が「Mac に接続中」のまま残っていました。iPhone 側で「接続解除」を押すしかなく、押すと macOS がその iPhone を隠すため、次の「マイクを入れる」で見つからなくなっていました。録音デバイスを名前で選んでいる場合に、マイクを切っても録音中の印が消えない問題も同じ原因で、あわせて直りました。
- **iPhone との接続が切れたら知らせます**: iPhone で録音中に接続が切れると、Mac のマイクへ黙って切り替えず、マイクを切って戻し方を知らせます。
- **ヘルプに戻し方を足しました**: iPhone 側で「接続解除」を押したあとは、Mac を一度スリープさせて戻すと iPhone が見つかります(戻らなければケーブルでつなぐ)。止めるときは Mac の「マイクを切る」を使ってください。
- **診断**: `--release-check [--device 名]` で、録音を閉じたあとにデバイスが止まっているかを確かめられます。
- **テンプレートの補完で、文を置く場所をアプリが決めるようになりました**: 「ヘイクロード」の補完で、Claude は使う所見の文だけを選び、正常所見のどこに置くか・どの文と差し替えるかはアプリが決めます。同じ依頼なら毎回同じ並びになり、「軽度」「高度」などの程度の語で出る行が決まり、「多発」「散在」は言われた通りに残ります。性別・年齢・精査目的(「若い女性」「腹痛精査」など)に合う文だけを置きます。
- **テンプレートの「構造」**: そのために、テンプレートごとに行の項目や所見の置き方をまとめた「構造」を Claude が付けます(`structure.json`。辞書ファイルは書き換えません)。辞書の窓の「構造」で確かめて直せます。**AI 訂正の接続を設定している場合、起動時と辞書の保存時に、まだ構造の無いテンプレートの本文・所見の部品・注記を Claude へ送ります**(初回は 14 件で 2 分ほど。接続が無ければ送らず、補完は今までどおり働きます)。
- **依頼の指示(request.md)の既定を直しました**: 上の変更に合わせた内容です。手元のファイルが 1.1.0 の既定のままなら、次の起動で 1 回だけ書き換えます(前の内容は `backup/` に残ります)。書き換えていた場合はそのままです。
- **モデルと配布物の取得先**: 認識モデルは Hugging Face からだけ取ります。インストーラ(`install.sh`)は、アプリ本体を GitHub の最新の release から取ります。
