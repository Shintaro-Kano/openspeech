音声認識アプリは、AI統合へ

OpenSpeech は、Mac で日本語を音声入力するアプリです。認識した文章は専用の編集欄で確認し、⌘Enter で、直前まで使っていたアプリに入力されます。

Mac にインストール GitHub

Apple Silicon · macOS 15 以降 · 無料 · オープンソース(MIT) · アカウント不要 · テレメトリなし

Features

4 つの特長

放射線科の日常業務での使用を想定して作っています。使う機能は、設定で選べます。

Mac の中で音声認識

認識は Haas-ja v1.0 を使い、Mac の中(Metal)で実行します。音声は Mac の外に出ません(自分の鍵で外部の音声認識 API を選んだときを除く)。macOS 26 では、macOS 内蔵の音声認識を選ぶこともできます。

AI 訂正(任意)

ご自身の Claude API キーか、Mac内 の Claude Code を設定した場合だけ、認識の誤りを Claude が直します。送るのは文字だけで、音声は送りません。既定では使いません。

学習・辞書・テンプレート

直した語は学習して次回から置き換え、よく使う語は辞書に登録できます。「ヘイクロード」と話しかけると、登録したテンプレートの補完や、文章の手直しを依頼できます(どちらも任意で、Claude API キーか、Mac の Claude Code が必要です)。公開のテンプレートライブラリから取り込み、自分のテンプレートを共有することもできます。

使っていたアプリへ入力

確定した文章は、直前に前面にあったアプリへ入力します(macOS のアクセシビリティを使用。使えない場合は貼り付け)。録音キーは既定で Caps Lock で、設定で変えられます。iPhone を連携させ、マイクにすることもできます。

Install

インストールは、コマンドをひとつ貼るだけ

ターミナルを開き、次の 1 行を貼り付けて実行します。

curl -fsSL https://openspeech.unitedradiology.jp/install.sh | bash
Intel Mac では動きません。インストーラは Apple Silicon 以外の Mac では、何も入れずに終了します。

動作環境

  • Apple Silicon の Mac(Intel Mac は非対応)
  • macOS 15 以降
  • macOS 内蔵の音声認識を使う場合は macOS 26

初回の設定

  • アプリを開き、「モデルを取得」を押すと、認識に使うモデルをダウンロードします(約 656 MB と約 1.2 MB)。
  • システム設定 → プライバシーとセキュリティ → アクセシビリティで OpenSpeech を許可します。
  • マイクの許可は、初めて使うときに macOS が確認します。
Trust

安全性と、外に出る情報

ソースコードはすべて公開しています。何が Mac の外に出るかは、次のとおりです。

このアプリについて

  • オープンソース(MIT)。ソースは GitHub にあります。
  • 無料です。アカウント登録は要りません。
  • 利用状況の送信(テレメトリ)はありません。アプリ内の更新確認もありません。
  • 音声は Mac の外に出ません。例外は、自分の鍵で外部の音声認識 API(OpenAI・Deepgram・Gemini Flash)を選んだときで、声と判定した発話の音声をその API に送ります。

外に出る通信(すべて)

  • モデルの取得: 「モデルを取得」を押したときだけ、Hugging Face からダウンロードします。
  • AI 訂正・テンプレートの補完: 有効にして設定した場合だけ、認識した文字(直前の最大 200 文字、登録語、学習した修正の例などを含む)を Claude(api.anthropic.com)に送ります。開発者向けの「この Mac の Claude Code」を選んだ場合は、Claude Code を通して Anthropic に送ります。音声は送りません。
  • 外部の音声認識 API: 選んで鍵を入れた場合だけ、声と判定した発話の音声と辞書の単語を、選んだ API(api.openai.com・api.deepgram.com・generativelanguage.googleapis.com のどれか)に送ります。
  • テンプレートの共有ライブラリ: 辞書の「共有ライブラリから取り込む」を押したときだけ、GitHub Pages(shintaro-kano.github.io)から公開テンプレートの目録を取得します。「共有」はお使いのブラウザで GitHub の投稿フォームを開くだけで、アプリ自身は何も送信しません。
  • インストール・更新: 手動で実行したときだけ、このサイトに接続します。
  • macOS 26 の内蔵音声認識を選んだ場合、macOS が言語データをダウンロードすることがあります。
Updates

更新と削除

更新も、同じコマンドをもう一度実行するだけです。アプリは自動では更新されません。

curl -fsSL https://openspeech.unitedradiology.jp/install.sh | bash
更新のたびに、アクセシビリティの許可をやり直してください。このアプリは Apple Developer Program を使わない簡易署名(ad-hoc)のため、入れ替えると許可が無効になります。インストーラが許可をリセットするので、システム設定 → プライバシーとセキュリティ → アクセシビリティで、もう一度許可してください。

アンインストール

次のコマンドで、アプリだけを削除します。設定・辞書・モデルなどのデータ(約 0.7 GB)は、~/Library/Application Support/OpenSpeech/ に残ります。

curl -fsSL https://openspeech.unitedradiology.jp/uninstall.sh | bash
Notes

注意事項

医療機器ではありません

OpenSpeech は医療機器ではなく、診断や治療のためのものではありません。音声認識も AI 訂正も誤ることがあります(たとえば、似た名前の検査)。認識した文章と訂正した文章は、使う前に必ずご自身で確認してください。

モデルの出典

Haas-ja v1.0(Third Intelligence、Apache-2.0)の sakasegawa 氏による非公式 GGUF 変換(Hugging Face で公開)を使っています。音声区間の検出には Silero VAD v6.2(MIT)を、実行には speech.cpp と ggml(MIT)を使っています。詳細は GitHub の THIRD-PARTY-NOTICES をご覧ください。
