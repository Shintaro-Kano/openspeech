Speak, and the text goes into the app you were using

OpenSpeech is a Mac app for dictating Japanese. Speech recognition runs on your Mac. You check the text in the app's own editor, then press ⌘Enter to type it into the app that was in front.

Install for Mac GitHub

Apple Silicon · macOS 15 or later · Free · Open source (MIT) · No account · No telemetry

Features

Four features

Made with everyday radiology work in mind. Each option can be turned on or off in Settings. The app speaks and recognizes Japanese.

Recognition on your Mac

Recognition uses Haas-ja v1.0 and runs on your Mac (Metal). Audio does not leave the Mac unless you choose an external speech recognition API with your own key. On macOS 26 you can choose the built-in Apple speech recognizer instead.

Optional AI correction

Only if you enter your own Claude API key (or choose Claude Code on this Mac), Claude is used to correct the recognized text. Only text is sent, never audio. It is off by default.

Learning, dictionary, templates

Words you correct are learned and replaced next time, and you can register your own words. Say 「ヘイクロード」 to ask for completion of a registered template (also optional; it needs a Claude API key or Claude Code on this Mac). You can also import templates from the public template library and share your own (1.1.0).

Types into your app

Confirmed text is typed into the app that was in front (through macOS Accessibility; it falls back to paste). The record key is Caps Lock by default and can be changed. An iPhone can be used as the microphone.

Install

Install by pasting one command

Open Terminal, paste this line and run it.

curl -fsSL https://openspeech.unitedradiology.jp/install.sh | bash
It does not run on Intel Macs. On anything other than Apple Silicon the installer exits without installing. Installing this way does not trigger the macOS "unidentified developer" prompt.

Requirements

  • A Mac with Apple Silicon (Intel Macs are not supported)
  • macOS 15 or later
  • macOS 26 if you want the built-in Apple speech recognizer

First run

  • Open the app and press "モデルを取得" (get models) to download the recognition models (about 656 MB and 1.2 MB).
  • Allow OpenSpeech in System Settings → Privacy & Security → Accessibility.
  • macOS asks for microphone permission the first time you use it.
Trust

Trust, and what leaves your Mac

The source code is public. This is everything that leaves the Mac.

About the app

  • Open source (MIT). The source is on GitHub.
  • Free. No account is needed.
  • No telemetry, and no update check inside the app.
  • Audio never leaves the Mac, except when you choose an external speech recognition API (OpenAI, Deepgram or Gemini Flash) with your own key: then the audio of utterances judged as speech goes to that API.

Network use (complete list)

  • Model download: only when you press the button, from Hugging Face.
  • AI correction and completion: only if you enable and configure them, the recognized text (with up to 200 preceding characters, registered words and examples of learned corrections) is sent to Claude (api.anthropic.com), or, with the developer option "Claude Code on this Mac", to Anthropic through Claude Code. Audio is not sent.
  • External speech recognition API: only if you choose one and enter its key, the audio of utterances judged as speech and your dictionary words go to that API (api.openai.com, api.deepgram.com or generativelanguage.googleapis.com).
  • Shared template library (1.1.0): only when you press "Import from the shared library" in the dictionary, the public template index is fetched from GitHub Pages (shintaro-kano.github.io). "Share" only opens GitHub's submission form in your browser; the app itself sends nothing.
  • Install and update: the installer contacts this site only when you run it.
  • If you choose the built-in recognizer on macOS 26, macOS may download language assets.
Updates

Updating and removing

To update, run the same command again. The app does not update itself.

curl -fsSL https://openspeech.unitedradiology.jp/install.sh | bash
Allow Accessibility again after every update. The app is signed ad hoc (without the Apple Developer Program), so replacing it invalidates the permission. The installer resets it; allow OpenSpeech again in System Settings → Privacy & Security → Accessibility.

Uninstall

This command removes the app only. Your settings, dictionary and models (about 0.7 GB) stay in ~/Library/Application Support/OpenSpeech/.

curl -fsSL https://openspeech.unitedradiology.jp/uninstall.sh | bash
Notes

Notes

Not a medical device

OpenSpeech is not a medical device and is not for diagnosis or treatment. Speech recognition and AI correction can both be wrong (for example, with similar exam names). Always check the recognized and corrected text before you use it.
